# Мастерская героя

Конструктор персонажа и справочник по таблицам игры (таблица игрока + книга ГМ `Manual_DM_RPG.xlsm`).
Статический сайт: без сервера, без сборки и без платного хостинга — работает на GitHub Pages.

## Что внутри

| Раздел | Что делает |
| --- | --- |
| **Создание** | 9 шагов: раса → возраст → дар/благословение/болезнь → черты → характеристики → таланты → снаряжение → предыстория → лист. Справа — живая сводка и список ошибок. Фракцию и религию персонаж получает уже в игре, поэтому шага для них нет. |
| **Мои герои** | Сохранённые персонажи (хранятся в браузере), импорт и экспорт файлом, сравнение двух героев. |
| **Справочник** | Открыто всем: расы (включая ♥ и ♠), магия, дары и проклятия, черты, материалы и кристаллы, оружие и броня, предметы, мир. **Только по паролю ГМ:** бестиарий, навыки, социум (фракции, НПС, квесты), алхимия и кухня, артефакты, механики. Поиск в каждом разделе. |
| **Как считается** | Все формулы и принятые решения — чтобы ГМ мог проверить. |

На листе персонажа есть кнопки «Ссылка для ГМ» (персонаж целиком зашит в ссылку), «Скачать файл», «Печать / PDF» и «Скачать картинку» (JPG, нужен интернет — библиотека html2canvas грузится с cdnjs).

## Пароль ГМ

Закрытые разделы справочника открываются паролем, который выдал разработчик сайта (в этом файле его нет — храните отдельно).

- Данные закрытых разделов лежат в `data/locked.js` **в зашифрованном виде** (AES-256-GCM, ключ из пароля через PBKDF2-SHA256, 250 000 итераций). Без пароля их не прочитать, даже если открыть файлы сайта или исходный код страницы. Игроки этот файл даже не скачивают, пока не введут пароль.
- **Создание персонажа пароля не требует.** Всё, что нужно мастеру, лежит в открытых данных в сокращённом виде: возможные предки драконидов, таррэ и скордитов (только статы, размер, символ и навыки, без боссов и легенд), физические навыки и стойки для «Предыдущего опыта» (без цен), артефакты для «Расхитителя древностей» (название и эффект). Полные таблицы — дроп, обитание, цены, способы получения, улучшения монстров — только в закрытых разделах.
- Пароль вводится в любом закрытом разделе справочника. Галочка «Запомнить на этом устройстве» оставляет режим ГМ включённым; «Выйти» в меню справочника — выключает.
- В режиме ГМ в мастере создания дополнительно видны фракция и религия расы (справочно).
- **Сменить пароль** — пересобрать данные с новым паролем (см. ниже) и загрузить на GitHub новые `data/data.js` и `data/locked.js`.

## Как опубликовать на GitHub Pages (бесплатно)

1. Зайдите на github.com → **New repository**. Имя любое, например `dnd-heroes`. Тип — **Public** (Pages для приватных репозиториев требует платный план).
2. В новом репозитории нажмите **uploading an existing file** (или **Add file → Upload files**) и перетащите **содержимое** этой папки: `index.html`, `.nojekyll`, `README.md` и папки `css`, `js`, `data`, `tools`, `tests`. Нажмите **Commit changes**.
   - Файл `.nojekyll` может быть скрыт в проводнике — он не обязателен, но лучше загрузить.
3. **Settings → Pages → Build and deployment → Source: Deploy from a branch**, ветка **main**, папка **/ (root)** → **Save**.
4. Через 1–2 минуты сайт появится по адресу `https://<ваш-логин>.github.io/dnd-heroes/` (ссылка видна там же, в Settings → Pages).

Если на GitHub уже лежал старый сайт — удалите старые `app.js`, `data.js`, `styles.css` и загрузите эти файлы вместо них.

Проверить без интернета: просто откройте `index.html` двойным кликом (не загрузятся только шрифты — будут системные).

## Как обновить данные после правки таблицы

Сайт читает данные из `data/data.js` (открытое) и `data/locked.js` (зашифрованное), которые собираются из книги ГМ скриптом:

```bash
pip install openpyxl cryptography
python tools/build_data.py путь/к/Manual_DM_RPG.xlsm --password "пароль ГМ"
```

Если `--password` не указать, скрипт спросит пароль (или возьмёт его из переменной окружения `GM_PASSWORD`). Флаг `--no-lock` собирает всё открытым, без пароля.

Скрипт перезапишет `data/data.js` и `data/locked.js` — загрузите оба на GitHub вместо старых. Скрипт учитывает не только значения, но и цвет ячеек (частота бонусов рас, «за единицу / за предмет» у материалов, запретная/порицаемая магия, сложность вступления в общины, категории существ) и примечания к ячейкам (способности существ). Если менять структуру листов (переставлять колонки или блоки), скрипт нужно поправить.

При сборке исправляются явные орфографические ошибки в текстах таблицы (словарь `tools/spelling.py`: «не когда» → «никогда», «арболет» → «арбалет» и т.п.). Игровая терминология и авторские названия не трогаются. Сама таблица не меняется — правки применяются только к данным сайта; если какое-то исправление лишнее, удалите строку из словаря и пересоберите.

Проверка правил после изменений: `node tests/rules.test.js` (нужен Node.js). С переменной `GM_PASSWORD` тесты дополнительно проверяют расшифровку закрытых разделов.

## Настройки ГМ

`js/config.js` — значения, которых в таблицах нет или которые записаны неоднозначно:

- `AGE_RANGES` — границы возраста в процентах (пожилой ровно +50%, старец ровно +100% — верхняя граница);
- `START_MATERIALS` — материалы стартового снаряжения (из листа игрока, Этап 3);
- `START_ITEM_MAX_SKILL` — можно ограничить стартовые предметы уровнем навыка ремесла;
- `START_ITEMS`, `POTION_MAX` — 3 предмета, зелья не сильнее 50е.

## Решения по неоднозначным местам таблиц

- **Возраст.** «Ребёнок: от 0 до −50%» понимается как уровень от 0 до половины среднего; «юный» — от −50% до среднего; «взрослый» — ровно средний; пожилой — +50%, старец — +100% (верхняя граница). Все уровни целые (округление до ближайшего, 0,5 — вверх): средний уровень расы, уровень персонажа, уровни существ. Очки характеристик = 3 × (уровень персонажа − средний уровень); очки талантов = ⌊уровень / 5⌋.
- **ОД.** 30 ОД = игровой день — это мерило ГМ. У игрока на листе только прибавка ОД: возраст + размер + раса + черты + дар (например, «+2»).
- **Фракция и религия** со старта не выдаются: игрок получает их уже в игре, выйдя в мир. Их бонусы в создании не участвуют.
- **Черты.** «Немота» и «обычный» уравновешивают по 2 положительных, «проклят» — 3, «калека» — 2 за каждую убранную конечность (фразу «+2 очка положительных характеристик» поняли как положительные черты); на столько же растёт лимит положительных. Противоположные черты вместе взять нельзя. Черты можно брать повторно (эффекты складываются); не повторяются только черты-состояния: языки зверей и монстров, шаманизм, лидер, немота, калека, обычный, несобранный.
- **Зоркость.** Базовые 50 и бонусы (раса, черты, дары) считаются отдельно от прокачки: предел 100 только у вложенных очков таланта, общего предела нет.
- **«Предыдущий опыт»** даёт символ из обычных или порицаемых (запретные нельзя). **«Расхититель древностей»** выбрасывает обычный или проклятый артефакт.
- **Снаряжение.** Эффект материала «за единицу» умножается на общее число единиц предмета (у оружия — и влияющие, и не влияющие на урон; например, короткий меч из стали: 2 + 1 = 3 ед. × «5% оглушить» = 15%). Урон по-прежнему = урон материала × единицы, влияющие на урон. Размер расы меняет сырьё, урон, броню и требования на свой процент; штраф ловкости брони не масштабируется.
- **Полукровка.** Числовые бонусы и штрафы родителей делятся пополам с округлением к нулю; размер — один из размеров родителей.
- **Дракониды / таррэ** получают +10% статов выбранного предка из бестиария; у драконидов размер — на ступень меньше предка, знак рода — символ предка. Список предков открыт, пароль для этого не нужен.
- **Эноши** выбирают зверо-предка из звериных рас и получают половину его бонуса.

## Структура

```
index.html          страница
css/style.css       оформление (тёмная тема, мобильная вёрстка, печать)
js/config.js        настройки ГМ
js/rules.js         все расчёты и проверки правил
js/ui.js            каркас приложения, сводка, маршруты
js/lock.js          пароль ГМ: расшифровка закрытых разделов
js/steps.js         шаги мастера создания
js/sheet.js         лист персонажа, страница «Как считается»
js/reference.js     справочник
js/heroes.js        сохранения, импорт/экспорт
data/data.js        открытые данные из таблиц (генерируется)
data/locked.js      закрытые разделы, зашифрованы паролем ГМ (генерируется)
tools/build_data.py сборщик данных из xlsm
tools/spelling.py   словарь исправлений орфографии для сборщика
tests/rules.test.js проверки правил
```
